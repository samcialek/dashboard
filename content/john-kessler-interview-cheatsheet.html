05 LLM BIAS → WHY BEHAVIOR MODELS TECHNICAL CREDIBILITY
"LLMs inherit the biases of their training data — English-language internet text skews liberal, Western, urban, educated. If you're simulating a population, you're baking in those biases as behavioral priors. That's not prediction, that's projection."
  • LLM training corpus: Reddit, news, Wikipedia — systematically overrepresents certain demographics and viewpoints
  • Positive/liberal bias in publications becomes positive/liberal bias in simulated agent behavior
  • A purpose-built behavior model trained on observed data (census, voting records, mobility, transactions) avoids this entirely
  • This is the core argument for moving from LLMs to LBMs — and it's a argument Aaru should be making to clients
"You need a model where the training signal is what people DID, not what the internet SAID about what people do."
06 SERIF — THE SAME ENGINE FOR PHYSIOLOGY DEPTH · VERSATILITY

Serif does the same for physiology — wearables, blood biomarkers, individual-level causal models. Same engine: partial pooling, latent state estimation, observed data to predictions."

07 MULTI-AGENT REINFORCEMENT LEARNING NEXT FRONTIER
"Right now your agents follow calibrated rules. With MARL, they learn strategies — and the population discovers equilibria you never programmed."
  • What MARL does: agents learn decision policies simultaneously in a shared environment, each adapting to what others do
  • Emergent behavior: agents discover strategies designers didn't anticipate — catches "black swan" population dynamics that rule-based sims miss
  • Realistic counterfactuals: agents react to policy changes with second-order effects (rent control → some leave, some change jobs, commute patterns shift)
  • Inverse RL: learn what agents "want" from observed behavior data instead of hand-specifying reward functions
  • Mean Field RL: scales MARL to millions of agents by approximating others as a population distribution — critical for Aaru's scale
  • Decision optimization: clients don't just want predictions, they want "what should we do?" — RL directly optimizes for outcomes
"You go from a model that replays the world with different parameters to one that plays the world and discovers what emerges."
08 AGENT × ENVIRONMENT DECOMPOSITION RL FRAMEWORK · ORIGINAL THINKING
"There are three modes of analysis: fix the world and vary the agent, fix the agent and vary the world, or vary both simultaneously."
  • Fixed world, vary agent: What can this agent actually affect? Tests the agent's action space — which levers matter?
  • Fixed agent, vary world: What scenarios might this agent face? Tests robustness — how does behavior change under different states of the world?
  • Vary both (MARL): Agents and environments co-evolve → discovers Nash equilibria — stable outcomes where no agent benefits from changing strategy
"Map both dimensions simultaneously using multi-agent RL to find equilibrium outcomes — pricing, positioning, competitive dynamics. That's what Lumen and Dynamo should be doing."
  • Lumen application: find equilibrium pricing/positioning for clients — "if Walmart does X, how do competitors respond, and where does it settle?"
  • Dynamo application: policy interventions as environment changes → agents adapt → find new equilibrium
  • This is the leap from "what happens if" to "where does it end up" — simulation → equilibrium discovery
