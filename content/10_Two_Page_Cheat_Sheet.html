1. LLMs → Large Behavior Models CORE ARGUMENT
  • LLMs predict plausible text, not plausible actions
  • Training data bias: English internet text → liberal, Western, urban, educated
  • Published words ≠ representative behavior — certain types write, that's not everyone
  • Need models trained on observed behavior (census, voting, mobility, transactions)
"You need a model where the training signal is what people DID, not what the internet SAID about what people do."
2. Multi-Agent Reinforcement Learning NEXT FRONTIER
  • MARL: agents learn decision policies simultaneously in shared environments
  • Emergent behavior: discovers strategies designers didn't anticipate
  • Realistic counterfactuals: agents react to changes with second-order effects
  • Inverse RL: learn reward functions from observed data
  • Mean Field RL: scales to millions via population distribution approximation
"You go from a model that replays the world with different parameters to one that plays the world and discovers what emerges."
3. Agent × Environment Decomposition RL FRAMEWORK
  • Fix world, vary agent: What can this agent affect? Tests action space
  • Fix agent, vary world: What scenarios might they face? Tests robustness
  • Vary both (MARL): Co-evolve → discover Nash equilibria
  • Lumen: equilibrium pricing — "if Walmart does X, where does it settle?"
  • Dynamo: policy interventions → agents adapt → new equilibrium
4. Model Alignment via RL
  • Reward shaping from ground truth — match observed behavior distributions
  • Inverse RL for value alignment — infer objectives from observed choices
  • Distribution matching (KL divergence / Wasserstein) — aligned at every percentile
  • Adversarial validation — discriminator can't tell simulated from real = aligned
5. Bias Registry INFRASTRUCTURE
  • 5 categories: prompt bias, anchor bias, historical coverage, salience weighting, representativeness
  • Each with detection method and mitigation
"That's the kind of infrastructure I'd bring to Aaru's pipeline."
