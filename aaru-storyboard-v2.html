Agent Construction
"How do you build a single synthetic person?"
What Exists

Joint Probability Agent · ~103 Traits

Each agent = point in joint probability space P(X,Y) over 8^50 (~1045) configurations. ~50 variables, 8 discretization levels. Bayes' rule enforced bidirectionally — P(Y|X) and P(X|Y) must both hold.

System called "Audience Gen". Defines ~103 personality/demographic traits per agent. Currently shipping "second generation tenement traits" (v2 of trait definitions). Matt building logical consistency replacement module to catch incoherent trait bundles ("embers").

Also: LLM-as-agent (prompt with persona card) + classical ML agents (logistic regression, random forest).

⚡ Hauer: "8^50… more than all the data on the internet." Previously 8^300, collapsed for bias-variance.
⚡ Yoonduk: ~103 traits defined. All latent — "nothing you can directly observe."
⚡ Standup: Matt finishing logical consistency module in Audience Gen. PRs stacked, results "look really good."
Optimal

Hierarchical Bayesian Agent

Each agent = individual posterior drawn from population prior via partial pooling. Parameters are distributions, not point estimates. Borrows strength across agents, principled uncertainty.

  • Population hyperprior → subgroup prior → individual posterior
  • MCMC/VI inference (NUTS, SVI)
  • Uncertainty propagates end-to-end
Sam's Edge

Probabilistic Programming (NumPyro + NUTS)

18 months production experience building hierarchical Bayesian models in NumPyro. Individual posteriors from cohort priors — the Serif engine.

  • Replaces ad-hoc uncertainty with rigorous posterior inference
  • Model comparison via WAIC/LOO
  • Prior sensitivity analysis
  • Composable generative models
→ Direct plug-in to Aaru's joint P(X,Y) framework. Adds formal inference where they currently use heuristic traversal.

Population Architecture
"How do you build a million agents that look like a real population?"
What Exists

700-Variable Synthetic Population

Differentially private synthetic data across 700 variables generated in seconds. Vastly exceeds NVIDIA's 6-variable personas. Census Bureau spent $100M on inferior capability.

Top-down demographic allocation from census marginals. Traits assigned from conditional distributions. Heterogeneity is core philosophy — no archetypes or clustering. Every individual modeled with intersecting identities.

Headcount: 24 people (as of visit #2), growing quickly. Research team: Matt, Yoonduk, Mateusz, John. Engineering: Kasia, Andrew, others. Revenue: Patrick. CEO: Cameron Fink. CTO: John Kessler.

⚡ Hauer: "We can make something in 700 variables." Refuses archetypes — "the real world is messiness."
⚡ Standup: 24 headcount, closing new engineering hires. Agent SDK in development.
⚡ Yoonduk: traits are all latent — derived from behavior, never directly observed.
Optimal

Generative Population Modeling

Train a generative model (VAE, normalizing flows, copula) on microdata. Sample new populations statistically indistinguishable from real ones but fully synthetic.

  • Correlational structure preserved naturally
  • Generate populations for places/times with no data
  • Compositional: condition on known marginals
Sam's Edge

Partial Pooling Across Subgroups

Hierarchical model where agent parameters drawn from subgroup-level distributions. Archetypes as cluster centers, individuals as draws from archetype distributions.

  • Handles sparse subgroups naturally
  • Uncertainty propagates correctly
  • No hard clustering — soft membership
→ Direct PRISM architecture. Individuals aren't forced into archetypes — they're probabilistic draws from archetype distributions.
03
Behavior Simulation
"Given an agent with traits, how do you predict what they do?"
What Exists

Joint Distribution Sampling + LLM

Behavior derived by conditioning P(X,Y). Both forward and reverse must be consistent. Also uses LLM completion for open-ended scenarios.

Yoonduk tension: Trade-off between black-box neural nets (better F1 scores) vs. interpretable trait variables (explanatory power). "Do we just really want to predict the next thing really well?" vs. variables that offer prescriptive value.

Confirmed gaps: No counterfactual simulation. No reverse/abductive simulation. Cyclic variable dependencies make topological sort impossible — "a lot of everything eating up into each other."

⚡ Hauer: "We operate in P(X,Y)… both forward and reverse probability must hold."
⚡ Yoonduk: "Tricky part — the interactions, a lot of recursive components." Cyclic dependencies break DAG assumption.
⚡ Yoonduk: Variables valued for explanatory + prescriptive power, not just predictive accuracy.
Optimal

Causal + Counterfactual Simulation

Transform correlational joint into causal structure. Pearl's Ladder: association → intervention → counterfactual. Enables P(Y | do(X)) queries.

  • do-calculus for intervention queries
  • SCMs for counterfactual reasoning
  • Abductive: outcome → best explanation
Sam's Edge

Causal DAGs + Abductive Inference

PRISM's 14-node L3 DAG implements causal structure. Enables P(Y | do(X)) for counterfactuals and abductive reasoning. Resolves Yoonduk's cyclic dependency problem by enforcing directed structure with explicit feedback paths.

  • Fills gap: Counterfactual simulation
  • Fills gap: Reverse/abductive simulation
  • Fills gap: Cyclic → directed with explicit time indexing
⚡ Hauer called abduction "really fucking weird" — it's standard philosophy of science.
⚡ Yoonduk acknowledged cyclicality kills topological sort — causal DAGs solve this.
→ Sam's causal DAGs + do-calculus directly enable both confirmed gaps and resolve the cyclic dependency issue.
04
Environment Modeling
"What world do the agents live in?"
What Exists

Client-Defined Static Scenarios

Define a scenario (election, marketing campaign, policy change) and ask agents to respond. Environment is a fixed prompt — no feedback loops, no agent-agent interaction. Butterfly effect problem: changing one minor detail in context can produce wildly different outputs.

Diverse client base: political elections (Mississippi midterms upcoming), marketing (sneakerheads / Foot Locker $100M ad buy), hardware store sensitivity mapping (ICE raid heat maps), fantasy drink market share.

Uncapitalized IP: Adversarial simulation (competitor modeling) and organizational simulation (what happens if we fire Bob? return-to-office mandate?) are conceptualized but not productized.

⚡ Yoonduk: "The product dictates that you don't really need to explore [dynamic environments] that much." Clients want cross-sectional snapshots.
⚡ Yoonduk: "Such a butterfly effect — change one minor detail about the context, very big change from original."
⚡ Hauer: massive untapped product potential in org + adversarial simulation.
Optimal

Dynamic Environment with Feedback

Environment as a dynamic system agents interact with. Economy, media, social networks as explicit stochastic processes. Enables feedback loops, contagion, tipping points.

  • Agent-agent interaction networks
  • Environment state updates from agent actions
  • Emergent macro phenomena from micro rules
Sam's Edge

Exogenous Refraction Layers

PRISM models environment as refraction layers that mediate between disposition and behavior. [F] Formative, [M] Milieu, [CA] Choice Architecture.

  • Separates what's modelable from what's not
  • Macro layers = observable, micro = stochastic
  • PCA on context space to identify key scenario axes
→ Directly addresses Yoonduk's butterfly effect concern. Instead of simulating every possible context, identify principal scenario axes and simulate those.

Validation & Calibration
"How do you know the simulation is right?"
What Exists

Continuous Calibration + Benchmarking

Joint distribution continuously anchored against observed data. Real data identifies populated regions of 8^50 space. Aggregate election results benchmarked against actual outcomes.

Backtesting ideas (John): Web search result ablation — remove information and test if predictions still hold. Exploring "new modalities of simulation for backtesting." Mississippi midterms as upcoming test case.

Calibration challenge (Yoonduk): Client feedback is often about marketing outcomes, not underlying trait accuracy. Hard to validate latent traits directly — "there's a layer between what is simulated and the observations." Data sparsity: diverse clients mean few repeated observations.

⚡ Hauer: "Real-world data interfaces with the model the whole way."
⚡ John: exploring backtesting via web search ablation.
⚡ Yoonduk: "Average is better than half because the tails roll really messed up." Calibration hard when traits are latent.
Optimal

Posterior Predictive Checks

Generate simulated data from the model, compare to real data. If indistinguishable → well-calibrated. Plus individual plausibility: detect impossible trait bundles.

  • PPC: Bayesian gold standard for model checking
  • WAIC/LOO for model comparison
  • Calibration plots for probabilistic predictions
Sam's Edge

Bayesian Model Checking Pipeline

Standard Bayesian workflow: posterior predictive checks, individual plausibility scoring (the "embers" problem Matt is manually fixing), WAIC/LOO model comparison, prior sensitivity analysis.

  • Detect incoherent trait bundles at scale (automates Matt's manual ember-fixing)
  • Compare model variants rigorously
  • Addresses Yoonduk's latent variable validation concern — PPC validates downstream observables even when traits are latent
→ The "embers" problem is exactly what Matt is spending weeks on manually. PPC + plausibility scoring automates this. Validates latent traits through observable predictions.
06
Temporal Dynamics
"How do agents change over time?"
What Exists

Snapshot with Markov Checkpoints

Generate a population at a point in time, simulate one event. Clients mostly want cross-sectional snapshots. Use Markov assumption: current state represents all history.

Known limitation (Yoonduk): "Decisions from 20 years ago might matter." Markov assumption acknowledged as insufficient for long-range effects. Exploring checkpointing: "like a Markov chain — imagine everything before is represented in the current state."

Thinking about "new modalities of simulation for past population" backtesting but early stage.

⚡ Yoonduk: "Most of our clients are cross-sectional — a snapshot in the timeline."
⚡ Yoonduk: "Decisions from 20 years ago might seem to [matter] a year later." Markov too limiting.
⚡ John: exploring "new modalities of simulation" for backtesting with real-world data.
Optimal

Online Bayesian Learning

Agents update beliefs in real-time as new data arrives. Sequential Monte Carlo, particle filtering, or variational online updates. Population posteriors evolve continuously.

  • Prior → data → posterior → new prior
  • No full re-training needed
  • Rolling forward with error accumulation detection
Sam's Edge

Phase Transitions + CVaR

PRISM insight: most of life = feed-forward DAG (steady state). But phase transitions (divorce, war, migration) re-open formative layers and re-refract personality. Solves Yoonduk's Markov concern: the prior posterior itself encodes long-range history.

  • DAG = steady state, RL = phase transitions
  • CVaR: Optimize for tail risk, not just means
  • Client chooses risk posture → different strategy
⚡ Hauer loved the CVaR pitch. "Geometry of Preference" — distributional preference differences.
⚡ Yoonduk wants rollback: "roll things back, change things, roll forward" — exactly counterfactual + phase transitions.
→ Online Bayesian learning formalizes Aaru's "continuous calibration." Phase transitions + CVaR add decision-theoretic output. Posteriors carry history beyond Markov.
